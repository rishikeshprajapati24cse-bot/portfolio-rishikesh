# Responsive Portfolio Website

Built with:
- HTML5
- Bootstrap 5.3
- CSS3
- JavaScript
- Bootstrap Icons

## Run locally
Open `index.html` in a browser.

## Personalize before final submission
Replace:
1. Personal contact details and links
2. About text
3. Skills and percentages
4. Project names/descriptions
5. Education details
6. Email, LinkedIn, GitHub and location

The supplied profile photograph is in `assets/profile.jpg`.

## Hosting
This is a static website and can be hosted on GitHub Pages, Netlify, Vercel or any static hosting service.
